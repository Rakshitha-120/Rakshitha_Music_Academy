MOUKTHIKA MUSIC ACADEMY WEBSITE
================================

Files:
index.html      - Home page
about.html      - About page
courses.html    - Courses page
classes.html    - Class timetable
events.html     - Events page
gallery.html    - Image gallery
contact.html    - Contact form
login.html      - Student login
register.html   - Student registration
dashboard.html  - Student dashboard
css/style.css   - Complete styling
js/script.js    - Navigation, registration, login, dashboard logic
images/         - Folder reserved for local images

HOW TO RUN:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. For student login, open Register, create an account, then login.
4. Registration/login data is stored in browser localStorage for this student-project demo.

NOTE:
The displayed gallery/hero images use online Unsplash image URLs. You can replace them with your own images by putting files in the images folder and changing the image URLs in the HTML/CSS.
